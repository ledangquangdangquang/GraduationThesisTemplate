\subsection{Trình bày thuật toán}
Thuật toán viết bằng mã giả với gói \texttt{algorithm} (khung và chú thích) và \texttt{algpseudocode} (các lệnh \verb|\State|, \verb|\For|, \verb|\If|, \verb|\Return|, \dots). Thuật toán \ref{tt:dft} tính DFT trực tiếp theo PT \ref{pt:dft}, với độ phức tạp $O(N^2)$.
\begin{algorithm}[H]
    \caption{Tính DFT trực tiếp}
    \label{tt:dft}
    \begin{algorithmic}[1]
        \Require Dãy $x[n]$, $n = 0, \dots, N-1$
        \Ensure Dãy $X[k]$, $k = 0, \dots, N-1$
        \For{$k = 0$ \textbf{to} $N-1$}
            \State $X[k] \gets 0$
            \For{$n = 0$ \textbf{to} $N-1$}
                \State $X[k] \gets X[k] + x[n]\, e^{-j 2\pi k n / N}$
            \EndFor
        \EndFor
        \State \Return $X$
    \end{algorithmic}
\end{algorithm}

\subsection{Chèn mã nguồn}
\label{sec:manguon}
Mã nguồn dùng môi trường \texttt{lstlisting} (gói \texttt{listings}), có khung và font chữ đều cỡ 10pt. Tên ngôn ngữ trong tùy chọn \texttt{language} để tô đậm từ khóa:
\begin{lstlisting}[language=Python]
import numpy as np

def dft(x):
    # Tính DFT trực tiếp theo định nghĩa, độ phức tạp O(N^2)
    N = len(x)
    n = np.arange(N)
    k = n.reshape((N, 1))
    return np.exp(-2j * np.pi * k * n / N) @ x
\end{lstlisting}
Chú thích trong mã nguồn viết được tiếng Việt có dấu như trên. Tệp mã dài nên chèn thẳng bằng \verb|\lstinputlisting{tep.py}| và đặt ở phụ lục.

\subsection{Danh sách liệt kê}
Danh sách không đánh số dùng \texttt{itemize}. Mẫu định dạng sẵn ba cấp với ba kiểu dấu đầu dòng khác nhau:
\begin{itemize}
    \item Mô hình kênh truyền gồm các tham số:
    \begin{itemize}
        \item Độ trễ (delay).
        \item Góc đến (AoA).
        \item Dịch tần Doppler, phụ thuộc vào:
        \begin{itemize}
            \item vận tốc phương tiện;
            \item tần số sóng mang.
        \end{itemize}
    \end{itemize}
    \item Nhiễu là nhiễu Gaussian trắng cộng tính (AWGN).
\end{itemize}
Danh sách đánh số dùng \texttt{enumerate}; kiểu số đặt bằng tùy chọn \texttt{label} của gói \texttt{enumitem}, ví dụ \verb|\begin{enumerate}[label=\alph*)]|:
\begin{enumerate}[label=\alph*)]
    \item Đo điện áp ra.
    \item So sánh với giá trị tham chiếu.
    \item Ghi kết quả vào Bảng \ref{bang:thinghiem}.
\end{enumerate}
